4. 직접 생성 방식의 공통 SQL 및 세 방식의 답변

  • ②·③: LLM이 작성 가능한 공통 SQL 예시
  • ①: §3.1의 두 조회 SQL 실행 후 행을 종합하여 동일 결과 산출
SQL두 방법의 공통 집계 SQL
긴 코드는 가로 스크롤 
SELECT COUNT(DISTINCT o.order_id) AS order_count,
       COALESCE(SUM(o.total_amount), 0) AS paid_amount_krw
FROM orders AS o
JOIN customers AS c ON c.customer_id = o.customer_id
WHERE c.city = :city
  AND c.membership_tier = :tier
  AND o.status = :status
  AND o.ordered_on >= :start_date
  AND o.ordered_on < :end_date;

  • WHERE: 질문의 조건 적용
